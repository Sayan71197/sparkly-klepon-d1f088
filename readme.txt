# Algae Bioproduction Workshop Website

Static responsive website created from the supplied National Workshop Information Brochure.

## Files
- `index.html` — complete website
- `assets/` — extracted brochure media assets

## Quick use
Open `index.html` in a browser.

## Publish
This can be uploaded to any static web host, including GitHub Pages, Netlify, Vercel, or an institutional web server.

## Links currently wired
- Registration: IIT Kharagpur ERP
- Abstract submission: Google Form
- Abstract template: supplied link

## Easy edits
Search in `index.html` for:
- dates
- speaker names
- fees
- registration/abstract links
- contact details
